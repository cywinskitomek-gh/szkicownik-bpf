Szkicownik BPF - wersja do telefonu (dziala bez internetu)

Pliki: index.html, manifest.webmanifest, sw.js, icon-180.png, icon-192.png, icon-512.png

Umieszczenie na GitHub Pages:
1. github.com -> "+" -> New repository. Nazwa np. szkicownik-bpf, Public, Create repository.
2. "uploading an existing file" -> przeciagnij wszystkie 6 plikow -> Commit changes.
3. Settings -> Pages -> Source: Deploy from a branch; Branch: main, folder / (root) -> Save.
4. Po 1-2 minutach strona jest pod adresem https://TWOJA-NAZWA.github.io/szkicownik-bpf/

Na iPhonie:
5. Otworz ten adres w Safari (z internetem).
6. Udostepnij -> "Do ekranu poczatkowego" -> Dodaj.
7. Otworz z ikony raz z internetem. Od tej chwili dziala tez w trybie samolotowym.

Zapis krzywej: "Zapisz plik .txt" -> "Zachowaj w Plikach" -> iCloud Drive.
W OM: pudelko bpf-from-text (biblioteka My_functions).

Aktualizacja: po zmianie plikow podnies w sw.js numer wersji (v1 -> v2) i wgraj pliki ponownie.
